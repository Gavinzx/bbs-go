# bbs-go CentOS 7 离线部署手册（SQLite 版）

版本：v1.0  
适用系统：CentOS 7.x x86_64  
数据库：SQLite（单文件，无需 MySQL）  
应用形态：Go 单进程 + 内嵌 SPA，端口 8082

---

## 1. 部署包内容

```text
bbs-go-centos7-sqlite-offline/
├── images/
│   └── bbs-go-centos7-sqlite.tar      应用镜像
├── docker-runtime/
│   ├── docker-20.10.24.tgz            Docker 静态运行时（可选）
│   └── docker-compose-linux-x86_64    Docker Compose 插件（可选）
├── config/
│   └── bbs-go.yaml                    默认 SQLite 配置
├── docker-compose.yaml                单服务 Compose
├── entrypoint.sh                      容器入口（复制配置、启动 Go）
├── load-images.sh                     加载镜像
├── install-docker.sh                  离线安装 Docker（可选）
├── deploy.sh                          一键部署
├── manual/
│   ├── 部署手册.md
│   └── 部署手册.pdf
└── SHA256SUMS                         文件校验和
```

**与 MySQL 版的区别：**

- 没有 MySQL 容器，也没有 3306 端口；
- 不启动 Node SSR，页面由 Go 二进制内嵌的 SPA 提供，对外只有 8082；
- 数据全部落在 `docker-data/`，备份只需打包该目录；
- SQLite 是单写者模型，适合单节点、中小规模；不要用多个容器副本同时挂同一个数据目录。

| 项目 | 建议 |
|---|---|
| 操作系统 | CentOS 7.9 x86_64（CentOS 7 已 EOL，仅作为兼容目标） |
| 内核 | 3.10 及以上 |

| 时区 | Asia/Shanghai |

检查系统：

```bash
cat /etc/centos-release
uname -r
free -h
df -h
```

## 3. 准备 Docker

### 3.1 已安装 Docker

满足以下条件可跳过本节：

```bash
docker version
docker compose version
```

要求 Docker 20.10+、Compose v2。若只有 `docker-compose` v1，请升级或使用包内 Compose 插件。

### 3.2 未安装 Docker：使用包内静态运行时

> 需要 root 权限。脚本会安装 Docker 20.10.24 和 Compose 插件，并注册 systemd 服务。

```bash
sudo ./install-docker.sh
docker version
docker compose version
```

如果 `docker` 启动失败，查看：

```bash
journalctl -u docker -n 100 --no-pager
```

CentOS 7 常见的存储驱动问题：

- 默认脚本使用 `overlay2`；
- 若内核/文件系统不支持，编辑 `/etc/systemd/system/docker.service`，把
  `--storage-driver=overlay2` 改成 `--storage-driver=vfs`，然后：
  ```bash
  systemctl daemon-reload
  systemctl restart docker
  ```
- `vfs` 更兼容但磁盘占用更大，只建议在兼容性排查时使用。

### 3.3 SELinux 与防火墙

查看 SELinux：

```bash
getenforce
```

如果是 `Enforcing` 且挂载目录出现权限问题，可选择：

```bash
# 测试环境临时关闭（重启后恢复）
setenforce 0

# 或给数据目录打容器标签
chcon -Rt container_file_t docker-data
```

开放端口（按实际端口调整）：

```bash
firewall-cmd --permanent --add-port=8082/tcp
firewall-cmd --reload
```

## 4. 部署

### 4.1 校验包完整性

```bash
sha256sum -c SHA256SUMS
```

### 4.2 一键启动

```bash
chmod +x deploy.sh load-images.sh install-docker.sh
./deploy.sh
```

指定宿主端口（例如 18082）：

```bash
BBSGO_WEB_PORT=18082 ./deploy.sh
```

脚本会：

1. 检查 Docker / Compose；
2. 加载 `images/bbs-go-centos7-sqlite.tar`；
3. 创建 `docker-data/{data,logs,uploads}`；
4. 启动 Compose。

检查状态：

```bash
docker compose -f docker-compose.yaml ps
curl -fsS http://127.0.0.1:8082/api/install/status
```

首次启动时 `installed` 为 `false`，属正常。

### 4.3 安装向导

浏览器打开：

```text
http://<服务器IP>:8082/
```

会跳转到 `/install`：

1. **数据库**：默认已选中 **SQLite**（配置 `db.type: sqlite`）。不要选择 MySQL；SQLite 无需填写地址和密码。
2. **站点信息**：填写站点名称、描述、**站点 URL**。站点 URL 必须是用户实际访问的地址，例如：
   ```text
   http://192.168.10.20:8082
   ```
   如果前面有 Nginx，填公网域名。
3. **管理员**：设置管理员用户名、密码、头像。
4. 点击安装，等待完成。

安装后检查：

```bash
curl -fsS http://127.0.0.1:8082/api/install/status
```

应返回类似：

```json
{"success":true,"data":{"dbType":"sqlite","dockerBuiltinMysql":false,"installed":true}}
```

数据文件：

```text
docker-data/
├── data/
│   ├── bbs-go.yaml        配置（安装后 installed: true）
│   ├── bbs-go.db          SQLite 数据库
│   └── topic_index/       Bleve 搜索索引
├── logs/bbs-go.log
└── uploads/               附件与图片
```

## 5. 日常运维

### 5.1 启停与日志

```bash
cd bbs-go-centos7-sqlite-offline

docker compose -f docker-compose.yaml ps
docker compose -f docker-compose.yaml logs -f bbs-go
docker compose -f docker-compose.yaml restart bbs-go
docker compose -f docker-compose.yaml stop
docker compose -f docker-compose.yaml start
```

### 5.2 健康检查

```bash
curl -fsS http://127.0.0.1:8082/api/install/status
docker inspect --format '{{.State.Health.Status}}' $(docker compose -f docker-compose.yaml ps -q bbs-go)
```

### 5.3 修改端口

在 Compose 同目录创建 `.env`：

```env
BBSGO_WEB_PORT=18082
```

然后：

```bash
docker compose -f docker-compose.yaml up -d
```

同时把后台“站点 URL”改成新端口，否则邮件/ sitemap 绝对链接仍指向旧地址。

### 5.4 修改配置

- 运行配置：`docker-data/data/bbs-go.yaml`；
- 修改后重启容器；
- 后台“系统设置”中的站点、登录、SMTP、上传等配置存数据库，不用改 YAML。

注意：**不要修改 `idCodec.key`**。它决定公开 ID 的编码，安装后修改会导致历史链接失效。

## 6. 备份、恢复与升级

### 6.1 备份

SQLite 必须避免在写入过程中直接复制。推荐停容器后打包：

```bash
docker compose -f docker-compose.yaml stop
tar czf bbs-go-backup-$(date +%F-%H%M).tar.gz docker-data
docker compose -f docker-compose.yaml start
```

至少包含：

- `docker-data/data/bbs-go.db`（数据库）
- `docker-data/data/bbs-go.yaml`（配置）
- `docker-data/uploads/`（附件）
- `docker-data/logs/`（可选）
- `docker-data/data/topic_index/`（可选，可重建）

### 6.2 恢复

```bash
docker compose -f docker-compose.yaml down
# 将备份的 docker-data 放回当前目录
docker compose -f docker-compose.yaml up -d
```

检查权限（容器默认以 root 运行）：

```bash
chown -R root:root docker-data
```

### 6.3 升级

```bash
# 1. 备份
docker compose -f docker-compose.yaml stop
tar czf bbs-go-before-upgrade.tar.gz docker-data
docker compose -f docker-compose.yaml start

# 2. 加载新镜像
docker load -i images/bbs-go-centos7-sqlite.tar

# 3. 重建容器（保留 docker-data）
docker compose -f docker-compose.yaml up -d --force-recreate bbs-go

# 4. 检查
docker compose -f docker-compose.yaml ps
docker compose -f docker-compose.yaml logs -f bbs-go
```

数据库迁移会在应用启动时自动执行。迁移只向前，没有自动回滚；回滚需恢复旧镜像 + 升级前数据目录。

## 7. 反向代理与 HTTPS（可选）

建议在 8082 前放 Nginx/Caddy：

```nginx
server {
    listen 80;
    server_name bbs.example.com;

    location / {
        proxy_pass http://127.0.0.1:8082;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

然后：

- 后台“站点 URL”改成 `https://bbs.example.com`；
- 防火墙只放行 80/443，8082 仅本机监听或限制来源；
- 不要在公网直接暴露 8082。

## 8. 故障排查

| 现象 | 处理 |
|---|---|
| `docker: command not found` | 运行 `sudo ./install-docker.sh`，或自行安装 Docker 20.10+ |
| Docker 启动失败 | `journalctl -u docker -n 100`；CentOS 7 尝试 `vfs` 存储驱动 |
| `permission denied /var/run/docker.sock` | 用 root 或把用户加入 docker 组后重新登录 |
| 端口被占用 | `ss -lntp | grep 8082`；用 `BBSGO_WEB_PORT` 改端口 |
| 页面打不开 | `docker compose ps`、`docker compose logs bbs-go`、`curl /api/install/status` |
| 安装页仍提示 MySQL | 确认 `config/bbs-go.yaml` 的 `db.type: sqlite`，或手动点击 SQLite |
| SQLite `database is locked` | 确认只有一个容器挂载该 `docker-data`；备份前先停容器 |
| 上传 404/无法写入 | 检查 `docker-data/uploads` 权限与挂载 |
| SELinux 拒绝挂载 | `setenforce 0` 验证，或 `chcon -Rt container_file_t docker-data` |
| 搜索无结果 | 后台“系统设置 → 搜索索引”重建 |
| 安装后重启又回到安装页 | 检查 `docker-data/data/bbs-go.yaml` 是否持久化、`installed` 是否为 true |

## 9. 安全建议

1. 首次安装使用强管理员密码；
2. 修改默认端口或限制来源 IP；
3. 生产使用 HTTPS 反向代理；
4. 定期备份 `docker-data`，备份文件包含数据库和配置，妥善保管；
5. 不要把 `docker-data` 放到多人可写目录；
6. CentOS 7 已停止维护，条件允许时迁移到受支持的操作系统；
7. 若启用 SMTP/OAuth，密钥保存在后台配置中，注意备份与访问控制。

## 10. 卸载

保留数据：

```bash
docker compose -f docker-compose.yaml down
```

彻底删除（**会丢数据，先备份**）：

```bash
docker compose -f docker-compose.yaml down
rm -rf docker-data
docker rmi bbs-go:centos7-sqlite
```
